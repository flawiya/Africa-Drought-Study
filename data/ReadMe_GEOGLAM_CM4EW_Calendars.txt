GEOGLAM Crop Monitor for Early Warning calendars
24 February 2026, v1.4

************************************************
Shapefile Columns:
country= Country for the subnational region
region= Subnational region name within the country
crop= Crop for which the calendar exists (See Crop list below for list of possible values)
planting= Starting date (day number 1-365) for the "Planting to Early Vegetative" stage
vegetative= Starting date (day number 1-365) for the "Vegetative to Reproductive" stage
harvest= Starting date (day number 1-365) for the "Ripening through Harvest" stage
endofseaso= Starting date (day number 1-365) for the "Harvest (End of Season)" stage
outofseaso= Starting date (day number 1-365) for the "Out of Season" stage
minimalpro= Areas of minimal to no production for the specific crop. 0 = monitored, 1 = not monitored, and no crop calendar associated with the region

************************************************
Crop list:
Maize 1, Maize 2, Sorghum 1, Sorghum 2, Millet, Winter Wheat, Spring Wheat, Teff, Rice 1, Rice 2, Rice 3, Beans 1, Beans 2, Beans 3

************************************************
Notes:
1) If the "outofseason" column has a value of "0", then there is no significant time in the year in which there is not activity in the fields.
